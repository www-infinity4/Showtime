# Showtime Channel

Showtime is the comedy, adventure, robots, science, and space station in the Infinity synchronized TV network. Every viewer in Live mode sees the program assigned to the current Central Time broadcast moment, with start-over, rewind, and Join Live controls.

## Launch rotation

- 2000–2026 full-length YouTube Movies rotation
- Without a Paddle, Paul, Bumblebee, Jules, A-X-L, Masterminds, and more
- twelve deterministic two-hour slots per station day
- three synchronized three-minute breaks inside each slot
- unavailable-source detection and automatic replacement
- channel metadata prepared for network-wide duplicate prevention

## Back burner

The three-minute breaks can later become twelve personalized 15-second placements. GPT commercial generation remains deliberately disconnected until the network has an approved Super Bowl–quality creative and safety standard.
